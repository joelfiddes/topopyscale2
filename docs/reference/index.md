# Reference

Exact, exhaustive descriptions of the interfaces. For explanations and worked
steps, start from [Get started](../get-started/index.md).

| Page | Source | How it is kept current |
|---|---|---|
| [CLI](cli.md) | `topopyscale2/cli/main.py` | Generated by `scripts/docs/gen_reference.py` |
| [Configuration](config.md) | `topopyscale2/config/schema.py` | Generated by `scripts/docs/gen_reference.py` |
| [Python API](api.md) | Docstrings | Read at build time by mkdocstrings |

Where a configuration key has no description, the schema has none yet. The fix is
a `Field(description=...)` (or a comment on the field) in the schema, followed by
re-running the generator, not an edit to the generated page.
