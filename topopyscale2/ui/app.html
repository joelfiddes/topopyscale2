Set up and run TopoPyScale

Simulation directory . Choose an area and a period, write the configuration, run, then view the result.

1 · Area

Click two opposite corners on the map, or type the bounding box in degrees.

2 · Period and options

Not set here: . Edit config.yaml for those; this page keeps them.

3 · Downscaling

How ERA5 is moved onto each terrain unit. The defaults are what the documentation and the demo use. See docs/downscaling_algorithms.md and the configuration reference for the physics.

4 · Run log

tps2 run in the simulation directory: terrain units, ERA5, then downscaling. The log is also written to ui_run.log.
