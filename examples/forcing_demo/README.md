# Davos forcing demo: one ERA5 grid cell, downscaled onto the terrain

**Open [`demo.html`](demo.html) in a browser.** It is a single ~1.1 MB file with no install and
no network: terrain, terrain units and a season of daily downscaled forcing are embedded.

It shows water year 2024 (1 Oct 2023 – 31 Jul 2024) over Davos and Weissfluhjoch, Switzerland,
where ERA5 sees smooth ground at about 2000 m and the real terrain runs from 1041 to 3097 m:

- **The map** shows one variable per day on the terrain (temperature, precipitation, snowfall,
  shortwave, longwave, wind, humidity). Press play to run through the season.
- **By elevation** plots every terrain unit's value against its elevation for the day shown,
  with a fitted line: the lapse the downscaling produces.
- **Through the season** charts any unit you click against the area mean, and the heatmap shows
  the whole season by 100 m elevation band.

```bash
open examples/forcing_demo/demo.html        # macOS
xdg-open examples/forcing_demo/demo.html    # Linux
```

## What to look for

| Layer | What the downscaling does |
|---|---|
| Temperature | −6.0 °C/km season-mean lapse across units; the page opens on the day the freezing level splits the area |
| Shortwave | 62–200 W m⁻² season mean from the most shaded to the sunniest unit: slope, aspect, shading and sky view |
| Snowfall | 565–1240 mm over the season, rising with elevation as more precipitation falls as snow |
| Precipitation | 1678–1790 mm: almost flat, because the elevation gradient is off by default |

Numbers from TPS2 0.1.0 @ 36679e8, run 2026-09-30; they are also stamped on the page.

## Rebuild the page (seconds, offline)

The run's terrain rasters and a compact daily summary of its forcing ship in `run/`
(`output/forcing_daily.nc`, 284 KB, int16-packed), so the page rebuilds with no network:

```bash
tps2 view examples/forcing_demo/run --page examples/forcing_demo/page.yaml \
    -o examples/forcing_demo/demo.html
```

The test suite runs exactly this and fails if the result differs from the committed `demo.html`
(`tests/test_outputs/test_forcing_page.py`). After an intended change, rerun the command and
commit the new page.

## Run it yourself, step by step (needs network)

```bash
examples/forcing_demo/run_demo.sh            # into ~/sim/davos_forcing_demo, or give a directory
```

The script copies `run/config.yaml` and runs the four steps, each of which also works on its own:

| Step | Command | What it does |
|---|---|---|
| 1. Set up the simulation | `tps2 setup --config config.yaml` | DEM, terrain analysis (slope, aspect, horizon, sky view), 150 terrain units; `tps2 info` summarises them |
| 2. Fetch ERA5 | `tps2 fetch-forcing --config config.yaml` | Surface and pressure-level ERA5 for the period; the long step (about an hour) |
| 3. Downscale | `tps2 run --config config.yaml` | Hourly forcing for every unit into `output/forcing.nc`; reuses steps 1 and 2 |
| 4. Results | `tps2 view . --page page.yaml --save-daily` | `output/forcing_page.html`, this page for your run |

Change the downscaling in `config.yaml` (or in `tps2 ui`) and re-run step 3: with the
terrain and ERA5 cached it takes seconds. The config uses Google ARCO-ERA5, which needs no
account. This page was made from a local copy of the same ERA5 data (13 minutes on a 40-core
machine, 22 s of it the downscaling of 150 units); the Google backend and a local ERA5 copy gave
bit-identical output for this domain (checked 2026-09-25).

Or do the same from a web page: `tps2 ui ~/sim/davos_forcing_demo` (choose the area on a map,
set the downscaling options, run, view).

## Files

| Path | What it is |
|---|---|
| `demo.html` | the page (generated by `tps2 view`; do not edit by hand) |
| `page.yaml` | the page's wording, credits and logo |
| `run/config.yaml` | the TPS2 configuration of the run |
| `run/dem_cache/` | the run's DEM and terrain-unit map |
| `run/output/forcing_daily.nc` | daily summary of the run's hourly forcing (`tps2 view --save-daily`) |
| `run_demo.sh` | the four steps above, from the command line |
| `branding/` | logo files used by `page.yaml` |
